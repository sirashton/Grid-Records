# Branding: the name and the mark

As of 2026-10-19:

- **Name: Gridstreak** (chosen 2026-10-19, "for now"). It says grid and record run, it is hard to misspell, and a web search found nothing that already owns it. The runners-up were Longspell, Emberless, The Long Run and Last Burn.
- **Mark: 3f-a, "Mix rows" in teal.** Four years of the fuel mix as 100% stacked rows, fossil on the left. The rows build once, then a dashed "lowest fossil share" line hops to the newest row. It lives in `site/js/core/hero-mark.js` (markup) and `site/style.css` (styles), and the favicon is `site/favicon.svg`.

The pages in this folder are the full set of options considered. Open them in a browser:

- `logo-options.html`: every animated mark from the later rounds (the 3-family fuel-mix cards, the 3f recolours, and the favicons drawn for 16px). The earlier rounds (the bar-chart "New record" family, the stopwatch dial and the flipping fleet board) are described in the PR that introduced the mark.
- `names-round-3.html`: fourteen names that all came out High for findability in a web search, with notes on German and Polish meanings and a top three across all rounds.
- `names-round-2.html`: about twenty more names chosen to be easy to find on Google, each with a search check and a findability rating.
- `names.html`: twenty candidate names in six groups, each shown next to the mark, with a tagline and a note on its strengths and weaknesses.
